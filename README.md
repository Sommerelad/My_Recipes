# המתכונים שלי 🍲

אפליקציית אינטרנט (PWA) אישית לאחסון וניהול מתכוני בישול, מותאמת לטאבלט Xiaomi
ולשימוש במטבח. כל הנתונים נשמרים על הטאבלט עצמו - אין צורך בחשבון או בחיבור
לאינטרנט לשימוש השוטף (אינטרנט נדרש רק לייבוא מתכון מאתר חיצוני).

## מה האפליקציה כוללת

- ממשק בעברית מלא, מימין לשמאל.
- הוספת מתכונים בשלוש דרכים: צילום מתכון כתוב-יד + הקלדה לתצוגה נקייה, ייבוא
  אוטומטי מקישור לאתר מתכונים, או הזנה ידנית.
- אחסון מתכונים לפי נושאים (קטגוריות) שאתם מגדירים - בהתחלה, ואפשר גם
  להוסיף/לשנות/למחוק בהמשך דרך ההגדרות.
- סימון מתכונים כמועדפים ⭐, בנוסף לשיוך לנושא.
- חיפוש חופשי בכותרת, במרכיבים, בהוראות ההכנה ובנושא.
- מסך המתכון בעיצוב "כרטיס מתכון" נקי וקריא, כמו תצוגת הדפסה.
- מניעת כניסת הטאבלט למצב שינה כל עוד האפליקציה פתוחה (Wake Lock).
- עובד גם ללא אינטרנט (אחרי הפעלה ראשונה), כולל גיבוי וייבוא בקובץ JSON.

## שלב 1: פרסום האפליקציה עם כתובת מאובטחת (חובה)

כדי שה"נעילת מסך" (מניעת כיבוי המסך) ואפשרות ההתקנה כאפליקציה יעבדו, הדפדפן
דורש שהאתר יוגש דרך **HTTPS**. הדרך הכי פשוטה וחינמית לעשות זאת היא עם
GitHub Pages:

1. פתחו חשבון GitHub חינמי (אם אין לכם) בכתובת github.com.
2. צרו מאגר (repository) חדש, לדוגמה בשם `my-recipes`.
3. העלו לתוכו את כל הקבצים מהתיקייה שקיבלתם (`index.html`, `manifest.json`,
   `service-worker.js`, התיקיות `css`, `js`, `icons`) - דרך "Add file → Upload
   files" באתר GitHub, ישירות מהדפדפן.
4. בהגדרות המאגר (Settings → Pages) בחרו להפעיל Pages מהענף `main`, תיקיית
   השורש `/`.
5. אחרי דקה-שתיים תקבלו כתובת כמו:
   `https://<שם-המשתמש-שלכם>.github.io/my-recipes/`
   זו הכתובת שתפתחו בטאבלט.

**חלופה מהירה יותר:** אפשר גם להשתמש ב-Netlify Drop
(app.netlify.com/drop) - גוררים לשם את תיקיית הקבצים, ומקבלים כתובת HTTPS
מיד, ללא צורך בחשבון GitHub. שימו לב שקישור כזה עלול להשתנות אם תיצרו גרסה
חדשה, אז לצורך שימוש קבוע GitHub Pages עדיף.

## שלב 2: התקנה על טאבלט ה-Xiaomi

1. פתחו את דפדפן **Chrome** בטאבלט (לא את דפדפן MIUI המובנה - חשוב שיהיה
   Chrome כדי שה-Wake Lock וההתקנה יעבדו כראוי).
2. גשו לכתובת ה-HTTPS שקיבלתם בשלב 1.
3. פתחו את התפריט (שלוש הנקודות) ובחרו **"הוספה למסך הבית"**
   (Add to Home screen).
4. אשרו - עכשיו יש אייקון של "המתכונים שלי" במסך הבית, ופתיחה ממנו תיפתח
   במסך מלא כמו אפליקציה רגילה, כולל עבודה גם כשאין אינטרנט.

## שימוש ראשוני

בפעם הראשונה שתפתחו את האפליקציה תופיע מסך הגדרת נושאים (קטגוריות) עם רשימת
ברירת מחדל (עיקריות, מרקים, סלטים, קינוחים, מאפים ולחמים, משקאות, תוספות).
אפשר למחוק, לשנות ולהוסיף נושאים לפי הצורך - וגם בהמשך, בכל שלב, דרך
"הגדרות".

### הוספת מתכון

לוחצים על כפתור ה-**"+"** העגול, ובוחרים אחת משלוש דרכים:

- **סריקת מתכון כתוב-יד**: מצלמים (או בוחרים תמונה קיימת) של דף המתכון,
  ואז מקלידים את הכותרת, המרכיבים וההוראות לתוך הטופס - כדי לקבל תצוגה
  דיגיטלית נקייה וקריאה. התמונה המקורית נשמרת גם היא, כתזכורת/גיבוי.
  (שימו לב: האפליקציה לא "קוראת" כתב יד אוטומטית - זו הקלדה ידנית חד-פעמית,
  שנותנת את התוצאה המדויקת ביותר).
- **ייבוא מהאינטרנט**: מדביקים קישור לעמוד מתכון באתר, והאפליקציה מנסה
  לשלוף אוטומטית כותרת, מרכיבים והוראות הכנה. זה עובד טוב באתרי מתכונים
  גדולים שמשתמשים במבנה נתונים סטנדרטי (schema.org). אם הייבוא לא מצליח
  (חלק מהאתרים לא נתמכים, או שחוסמים גישה), אפשר לעבור בקלות להזנה ידנית
  עם הקישור שמור כמקור.
- **הזנה ידנית**: כתיבת מתכון חדש מאפס.

בכל מקרה, בטופס אפשר לבחור נושא (קטגוריה), לסמן כמועדף, ולערוך הכל לפני
השמירה.

### חיפוש, נושאים ומועדפים

במסך הבית יש שורת חיפוש (מחפשת בכותרת, מרכיבים, הוראות ונושא) ושורת
"צ'יפים" לסינון לפי נושא או לפי מועדפים. אפשר לשלב חיפוש עם סינון.

### עריכה, מחיקה וגיבוי

בתוך מתכון אפשר לערוך או למחוק אותו. בהגדרות אפשר לנהל נושאים, ולייצא/לייבא
קובץ גיבוי (JSON) - מומלץ לייצא גיבוי מדי פעם, כדי לא לאבד מתכונים אם
משהו קורה לטאבלט.

## מגבלות ידועות

- **ייבוא מהאינטרנט** תלוי בשירות חיצוני חינמי (proxy) שמאפשר לאפליקציה
  לגשת לאתרים אחרים, ובכך שהאתר עצמו כולל "נתוני מתכון" סטנדרטיים בעמוד.
  לא כל אתר יעבוד אוטומטית - במקרה כזה, ההזנה הידנית עם שמירת הקישור היא
  הפתרון.
- **נעילת המסך מפני כיבוי (Wake Lock)** דורשת גרסת Chrome מעודכנת וכתובת
  HTTPS (או localhost). ברוב הטאבלטים המודרניים כולל Xiaomi זה עובד out of
  the box, אך אם המסך בכל זאת נכבה - בדקו שהאפליקציה נפתחה מתוך Chrome
  ושהכתובת מתחילה ב-`https://`.
- כל הנתונים נשמרים מקומית על הטאבלט (בתוך Chrome). מחיקת נתוני הדפדפן/הסרת
  האפליקציה תמחק גם את המתכונים - **לכן חשוב לייצא גיבוי מדי פעם**.

בתיאבון! 🍽️
